Privacy

Sandbox Executor

Your script runs inside a separate browser worker on your device. The Lua code has no access to the network, your files or this page. The sandbox imitates Roblox, so some scripts can tell the difference and behave differently or stop.

Browser tools

Detector, Beautifier, Basic Cleaner, Prometheus, LuaObfuscator, Clyde and Ironveil process your script in your browser. This site does not upload it for processing. Hercules in browser mode does the same, after downloading Python (Pyodide) from cdn.jsdelivr.net.

Hercules server mode

Only if you tick the server option, Hercules sends your script to this site's server function. The application code does not save or log the script. The hosting provider may keep technical request logs under its own policy.

Browser storage

Your theme choice is stored in your browser. When you move a script between tools, it is held briefly in session storage and removed when the next page reads it.
