How to use

1. Detect

Open the Detector, add your script and check the suggestion. It relies on headers and code structure, so some scripts may not be identified.

2. Deobfuscate

Open the matching tool, upload or paste the script and press Deobfuscate. If it fails, the version or settings may not be supported.

No matching tool?

Try the Sandbox Executor. It runs the script safely in your browser and lists what it does. It does not rebuild source code.

3. Review

Read the output before using it. It can be incomplete or behave differently from the original. Do not run unknown scripts just because they were decoded.

4. Format

Use the Beautifier to improve indentation.
